# Sartiq Post per Adobe Photoshop

Questo repository contiene esclusivamente i pacchetti ufficiali di Sartiq Post.
Non contiene il codice sorgente.

Versione pubblicata: **[0.2.50](https://github.com/shootify-io/sartiq-post-releases/releases/tag/v0.2.50)**.

## Installazione o aggiornamento

1. Salva eventuali lavori aperti in Photoshop.
2. [Scarica l'ultima versione di Sartiq Post](https://github.com/shootify-io/sartiq-post-releases/releases/latest/download/Sartiq-Post.ccx).
3. Fai doppio clic su `Sartiq-Post.ccx` e conferma l'installazione richiesta da
   Adobe Creative Cloud.
4. Apri Photoshop e seleziona **Plugins → Sartiq Post**.
5. Controlla la versione in fondo alla schermata di login oppure nel menu con le
   tue iniziali. Se compare ancora quella precedente, riavvia Photoshop una
   volta.

Adobe può mostrare un avviso perché il pacchetto viene distribuito fuori dal
Creative Cloud Marketplace. È normale per questo canale ufficiale Sartiq.

Dalla versione `0.2.47`, Sartiq Post segnala nella propria interfaccia quando è
disponibile un aggiornamento. L'aggiornamento non viene mai installato
automaticamente: il pulsante scarica questo stesso pacchetto e Adobe chiede
sempre conferma.

Il download è pubblico per evitare account GitHub agli operatori. L'accesso a
Sartiq e alle relative produzioni resta protetto dal login nel plugin.

Per consultare una versione precisa o le relative note, usa la sezione
[Releases](https://github.com/shootify-io/sartiq-post-releases/releases).
