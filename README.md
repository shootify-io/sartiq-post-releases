# Sartiq Post

Official Sartiq Post packages for Adobe Photoshop.

## Install or update

1. Download [the latest Sartiq Post package](https://github.com/shootify-io/sartiq-post-releases/releases/latest/download/Sartiq-Post.ccx).
2. Double-click `Sartiq-Post.ccx` and confirm the installation in Adobe Creative Cloud.
3. Reopen the Sartiq Post panel in Photoshop. If the loaded version has not changed, restart Photoshop once.

Access to Sartiq remains protected by the plugin sign-in. This repository contains release packages only; the source code is maintained privately.
